This sample Spring Boot e-commerce app demonstrates user registration, product CRUD operations, shopping cart simulation, and image upload.

All code, dependencies (Spring Boot, Hibernate, Thymeleaf), SQL schema, and libraries are in the project directory for easy reference.

Prerequisites include Java 11+, Maven 3.6+, and MySQL 5.7+—verify they’re installed and accessible before proceeding.

Clone the repo and update src/main/resources/application.properties with your database URL, username, and password.

Run mvn clean package to build the JAR, or launch the main class directly from your IDE.

The application starts at http://localhost:8080; explore REST endpoints under /api or use the Thymeleaf-based UI pages.

API documentation, sample Postman collections, and demo screenshots are provided in the docs and docs/images folders.
